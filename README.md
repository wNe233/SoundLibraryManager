# SoundLibraryManager 音效素材库

SoundLibraryManager 是一款面向影视剪辑师的本地音效管理工具。它不需要联网或登录，不内置音效，也不会复制和删除原始文件。素材索引、标签、分析结果与波形缓存都保存在本地。

**更快地找到需要的声音**

软件会对音频进行轻量离线分析，可按照时间形态、频率特征、动态变化和音高走势筛选素材。例如，可以快速缩小到“短音、低频、突强、升调”这一类结果，再配合搜索、自定义标签、收藏夹和文件夹层级继续筛选。

**在素材库中直接听、直接看**

每条素材都会展示由真实音频数据生成的波形。鼠标移到波形上即可定位预览位置，按空格从指针处播放；播放头会实时反馈进度。卡片视图适合浏览，列表视图适合大量素材的快速比较，两种视图都支持排序和即时预览。

**直接拖入剪辑时间线**

macOS 使用 AppKit 原生拖拽，Windows 使用 OLE `DoDragDrop` 与 `CF_HDROP`。拖出时，达芬奇和剪映接收到的是原始音频文件路径，因此可以把素材从软件直接放到媒体池或时间线，不创建中转文件。

**围绕本地素材库设计**

- 导入音频文件或完整文件夹，并保留原始子目录层级
- 支持 WAV、MP3、AIFF、AIF、M4A 和 FLAC
- 卡片与列表双视图，可调整卡片列数
- 按添加时间、名称、时长和格式排序
- 自定义标签、收藏夹与缺失文件检测
- 按文件内容识别重复音频，支持波形对比和选择保留项
- 右键新建、重命名和移除归类目录，支持框选与多选
- 可更改素材库和波形缓存位置，并查看或清理缓存
- 针对大素材库加入分批渲染、目录索引、筛选缓存和搜索防抖

**本地运行**

需要 Node.js 20 或更高版本。

```bash
npm install
npm start
```

**构建发布包**

macOS ARM64：

```bash
npm run build:native:drag
npm run build:mac
```

Windows x64 原生拖拽模块需要在 Windows x64 环境中构建：

```powershell
.\scripts\build-native-file-drag-win.cmd
node .\scripts\update-win-unpacked.js
```

发布前检查：

```bash
npm test
```

**数据与隐私**

素材库默认保存在系统应用数据目录的 `soundeffect.library` 中。`library.json` 保存路径、层级、标签、收藏和分析结果，`wave-cache` 保存波形与轻量识别缓存。清理缓存、移除素材或移除目录都不会删除原始音频。软件不包含联网、账号、上传或遥测功能。

**安装提示**

当前 macOS 和 Windows 发布包没有商业代码签名。macOS 首次打开时可能需要在“系统设置 -> 隐私与安全性”中允许；Windows SmartScreen 可能显示未知发布者。达芬奇右键导入依赖本机 Resolve 脚本接口，原生拖拽不依赖该接口。
